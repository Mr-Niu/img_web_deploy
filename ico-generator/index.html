How to create a favicon.ico

  1. 1 Upload a PNG, JPG, WebP, or GIF image. Square logos work best.

  3. 3 Choose preview size and corner radius, then click Generate ICO.
  4. 4 Download favicon.ico with all standard sizes (16–512 px) or a single size only.
  5. 5 Place the file in your site root and add link rel="icon" to your HTML.

What is favicon.ico?

favicon.ico is the classic website icon shown in browser tabs, bookmarks, and shortcuts. A single .ico file can contain multiple resolutions so it stays sharp on retina displays and older Windows shells. This tool builds that pack locally from your logo — nothing is uploaded.

Frequently Asked Questions

Are my images uploaded?
No. Cropping, rounding, and ICO encoding run entirely in your browser.
Which sizes are in the full favicon pack?
The all-sizes download embeds 16, 32, 48, 64, 128, 256, and 512 pixel frames in one favicon.ico file.
Can I download only one icon size?
Yes. Use the single-size download after generating to get an .ico with only your preview size.
Does transparency work?
Yes. PNG and WebP transparency is preserved in the ICO output.
How is this different from the image converter?
The image converter handles bulk format changes. This page is built for favicons: square crop, corner radius, and multi-size .ico output.
